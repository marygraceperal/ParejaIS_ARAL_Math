Lesson Plan: Absolute Value Concepts

Topic 3.1: Distance on a Number Line, Evaluating |x|, and Distance Between Points (ILAW Framework)

I – ILLUMINATE & INTRODUCE

1. Learning Objectives

  • Cognitive: Define absolute value as a geometric distance from zero on a number line and compute the distance between any two real numbers using d(a,b) = |a - b|.
  • Affective: Appreciate the concept of magnitude regardless of direction in real-world contextual measurements.
  • Psychomotor: Plot real numbers on a number line to construct visual distance models for evaluated expressions.

2. Initiating Hook

Ask students: "If you walk 5 blocks north to a store, your distance is 5 blocks. If you walk 5 blocks south back home, is your distance walked -5 blocks or 5 blocks?" Emphasize that while direction can be negative (vector position), physical distance (magnitude) is always non-negative.

L – LEARN

1. Mathematical Foundation

Define absolute value as distance from zero on a number line:

Piecewise Definition:

|x| = x if x ≥ 0

|x| = -x if x < 0

2. Evaluating Expressions & Distance Between Points

Demonstrate evaluating numerical expressions with absolute value bars acting as grouping symbols, followed by calculating distance between two points a and b using d = |a - b|.

Worked Examples:

a) Evaluate |3 - 9| + 2 = |-6| + 2 = 6 + 2 = 8

b) Distance between a = -8 and b = 4:

d = |-8 - 4| = |-12| = 12 units

⚠️ Common Diagnostic Misconception: Outer Negation

Warn students that absolute value bars do not neutralize negative signs located outside the bars. For example, -|-5| = -(5) = -5.

A – APPLY

Localized Real-World Applications

Application 1: Elevation and Sea Level Differences

If a coastal town's mountain peak is at +450 meters above sea level and a nearby submarine trench is at -120 meters below sea level, the total vertical distance between them is |450 - (-120)| = |570| = 570 meters.

Application 2: Financial Margin of Error & Variance

In business auditing, stock variance is measured by absolute value deviation: | Actual Stock - Expected Stock |. Whether inventory is over or under, variance magnitude measures reporting accuracy.

W – WIND-UP

1. Formative Self-Check Quiz

  1. Evaluate: |-14| - |6|
    Answer: 14 - 6 = 8
  2. Evaluate: -| -18 |
    Answer: -18
  3. Find Distance: Find the distance between x = -15 and y = -3 on a number line.
    Answer: |-15 - (-3)| = |-12| = 12 units

2. Key Takeaways Summary

  • Distance is Positive: Absolute value measures distance from origin or between points, which is always non-negative (|x| ≥ 0).
  • Grouping Priority: Always evaluate expressions inside | | before taking the absolute value.
  • Distance Formula: Distance between points a and b is |a - b| = |b - a|.
