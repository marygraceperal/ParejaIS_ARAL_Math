Concept Discussion: Absolute Value Concepts

Topic 3.1: Distance on a Number Line, Evaluating |x|, and Distance Between Points

1. Absolute Value as Distance from Zero

The absolute value of a real number x, denoted by |x|, represents its geometric distance from zero on a real number line.

Because distance measures spatial separation, absolute value is always non-negative (|x| ≥ 0).

← -5 | -5 | = 5 units 0 (Origin) | +5 | = 5 units +5 →

Formal Piecewise Definition

For any real number x:

|x| = x if x ≥ 0

|x| = -x if x < 0

Note: When x < 0, the expression -x negates a negative number, resulting in a positive value (e.g., if x = -4, then -x = -(-4) = 4).

2. Evaluating Absolute Value Expressions

Treat absolute value bars | | as grouping symbols. Evaluate all operations inside the bars first before applying the absolute value non-negativity property.

Expression Inner Evaluation Absolute Value Applied Final Value
| -12 | -12 -(-12) 12
| 7 - 15 | -8 -(-8) 8
-| -9 | -9 -(9) -9
| -3 | + | -5 | -3 and -5 3 + 5 8

3. Distance Between Two Points on a Number Line

The distance d between two points with coordinates a and b on a number line is given by the formula:

d(a, b) = |a - b| = |b - a|

Because |a - b| = |b - a|, the order in which you subtract coordinates does not change the physical distance.

Example: Find distance between a = -7 and b = 5

Method 1: |a - b| = | -7 - 5 | = | -12 | = 12 units

Method 2: |b - a| = | 5 - (-7) | = | 5 + 7 | = | 12 | = 12 units

4. Diagnostic Misconception Alerts

⚠️ Misconception 1: "Absolute Value Just Means Change the Sign"

Absolute value does not mean "flip the sign." It forces a distance to be non-negative. Positive values stay positive (|6| = 6); only negative values flip to positive (|-6| = 6).

⚠️ Misconception 2: Negation Outside the Bars

Absolute value bars cannot make an outside negative sign positive. In -| -4 |, the inner part evaluates to |-4| = 4, then the outer negative sign applies, yielding -4.
