1. Key Concepts: The Building Blocks of an Equation

An equation is like a balanced scale. It uses mathematical symbols to represent real-life situations. Every algebraic equation has four main component parts:

  • Variable (x, y, h, k): The unknown or changing quantity. It represents "how many" or "how much" of something depends on the situation.
  • Coefficient (m): The unit rate attached to the variable. It tells you the cost, rate, or value per item or per unit of time.
  • Constant (b): The fixed amount or starting value. It does not change, no matter how much the variable increases or decreases (e.g., base fees, starting balance, minimum charges).
  • Total Value (y or T): The final result or accumulated outcome after combining the fixed amount and the changing amounts.
Linear Equation Standard Form
y = mx + b
Total Value = (Unit Rate × Variable) + Fixed Constant

2. Guide Words for Setting Up Equations

Use this reference table to help you identify components in word problems:

Component Common Keywords / Phrases Example in Context
Variable "number of...", "hours worked", "distance in km" h = number of hours
Coefficient "per", "each", "every", "rate of" ₱50 per hour → 50h
Constant "fixed fee", "initial fee", "deposit", "base charge" ₱100 fixed transport allowance
Total Value "total cost", "final amount", "overall earnings" T = total earnings

3. Worked Example

Problem: A worker earns a fixed daily transport allowance of ₱100 plus ₱50 per hour worked (h). Write an equation representing their total daily earnings (E).

  • Total Value (E): Total daily earnings
  • Variable (h): Number of hours worked
  • Coefficient (50): Rate per hour (₱50/hr)
  • Constant (100): Fixed transport allowance (₱100)
Equation: E = 50h + 100
